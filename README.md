# Ocaua lui Cuza — site demo

Propunere realizată de Manotek pentru Restaurant & Cazare Ocaua lui Cuza (Tecuci).

- Conținut: `content/site.ts` (orice „[de completat]” apare evidențiat pe site)
- Formulare: setează `formspreeEndpoint` în `content/site.ts`
- Imagini: componentele `Placeholder` se înlocuiesc cu poze reale
- `npm run dev` · `npm run build` (export static în `out/`)
- Publicare automată pe GitHub Pages la fiecare push pe `main`.
